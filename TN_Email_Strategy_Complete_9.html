The Solution — Two Systems. Clear Separation. Mailchimp for Newsletters. SendGrid for Alerts.

Mailchimp stays for newsletters. SendGrid handles all transactional alerts. Two systems — each doing what it does best.

⚠️ Critical before go-live: Export all existing per-alert unsubscribe tokens from SendGrid → import into TN-D8-001 as suppressed. Mailchimp unsubscribe list must sync to the preference centre. Skipping this = GDPR violation.

Two systems. Each doing what it does best. Confirmed direction.

Mailchimp — Newsletters
✓ Editorial team manages newsletters — no workflow change
✓ Drag-drop editor retained
✓ A/B testing and marketing features stay
✓ Sends from newsletter domain
✓ 120K subscriber list stays in Mailchimp
SendGrid — Transactional Alerts
✓ All alerts go through TNOAlertMail → FundInfo Mail Service → SendGrid
✓ Sends from alerts@trustnet.com
✓ Watchlist, portfolio, Crown Rating, fund save/follow alerts
✓ Real-time event-driven delivery
✓ Preference centre writes to SendGrid subscriber store
Key dependency: Preference centre (TN-D8-001) must sync unsubscribes across both systems. Newsletter unsubscribes from Mailchimp must suppress alerts in SendGrid and vice versa. This is the critical GDPR requirement before go-live.
