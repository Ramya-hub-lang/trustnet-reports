What is TrustNet MCP?

Cloudflare AI Gateway
What is Cloudflare AI Gateway?
A layer that sits between AI agents and the TrustNet MCP server. Handles rate limiting, query logging, caching and freemium access control. Core features are free. One line of code to set up. Confirmed by Ramya as the approach for TrustNet MCP
What it does for TrustNet MCP
Rate limiting â freemium control

Set rules: unauthenticated agents get 4â5 queries per session. Registered users get more. Paid agents get unlimited. Cloudflare enforces this automatically without custom code.

Query logging

Every agent query is logged. TrustNet sees exactly what IFAs are asking â not through Claude's analytics (which we can't access) but through our own Cloudflare gateway logs. We own this data.

Caching

Repeat queries served from cache â faster responses, lower API costs. Up to 90% cost reduction on frequently asked questions. Critical for keeping free tier sustainable.

Analytics dashboard

Built-in dashboard shows: number of requests, token counts, query costs, latency, errors. Visualise query patterns, peak times, most popular queries. Free on all plans.

Payment gateway integration

Cloudflare AI Gateway charges agents per query or per API key. Same model as Bloomberg MCP and Ontra. Free tier enforced automatically â premium agents get API keys.

DLP scanning

Built-in data loss prevention. Scans queries and responses for sensitive information (financial data, personal identifiers). Free on all plans. Protects TrustNet data.
